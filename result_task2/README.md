## 5. 평가

### 5-1. 과적합이 뚜렷하다
- 학습 정확도 96% 대비 검증 정확도 77%로 **약 19%p 차이**가 난다.
- 검증 loss는 5 epoch(0.94) 이후 더 내려가지 않고 0.94~1.13 사이를 오간다. 반면 학습 loss는 계속 0.10까지 내려간다(`learning_curves.png`).
- 동현 실행에서는 최적 epoch이 마지막(12)이었지만, 현일 실행에서는 검증 정확도가 epoch 7→8에 74.1%→66.4%, 10→12에 77.1%→73.6%로 흔들렸다. 고정 학습률에서 epoch마다 변동이 크다는 관측이며, 학습률 스케줄의 효과는 아직 검증하지 않았다.
- 원인 후보(검증 안 됨): 사전학습 없이 시작했고 증강과 규제가 없다. 학습 이미지가 적은 차종도 있다(Patriot 학습 184장 등).

### 5-2. 어려운 차종은 Activity 1의 예측과 같다
F1이 가장 낮은 차종과 가장 많이 틀린 쌍이 Activity 1에서 짚은 "닮은 차종"과 겹친다.

| F1 하위 차종 | F1 | | 가장 많이 틀린 쌍 (정답 → 예측) | 장수 |
|---|---:|---|---|---:|
| dodge/ram_1500 | 0.39 | | honda/civic → accord | 133 |
| gmc/sierra_1500 | 0.42 | | dodge/ram_1500 → ram_2500 | 74 |
| bmw/328i | 0.45 | | gmc/sierra_1500 → chevrolet/silverado | 66 |
| bmw/528i | 0.50 | | toyota/corolla → camry | 58 |
| volkswagen/golf | 0.52 | | chevrolet/silverado → dodge/ram_1500 | 54 |
| jeep/cherokee | 0.53 | | chevrolet/corvette → ford/mustang | 49 |
| bmw/325i | 0.57 | | chevrolet/silverado → gmc/sierra_1500 | 48 |

- **형제차와 트림:** Silverado↔Sierra, Ram 1500↔2500, 325i↔328i↔528i, Golf↔GTI
- **같은 차체 유형:** 세단끼리(Civic↔Accord, Corolla↔Camry, Altima→Accord), 픽업끼리(Silverado↔Ram), 스포츠카끼리(Corvette→Mustang)

### 5-3. 이미지 수와 성능의 관계
- 학습 이미지 수(로그)와 F1의 상관계수는 0.44로, 약한~중간 정도의 양의 관계다(보고서와 같은 기준).
- 작은 클래스(Patriot 0.65, 530i 0.62, 528i 0.50, Golf 0.52)는 대체로 낮다.
- 하지만 F1이 가장 낮은 Ram 1500(검증 224장)과 Sierra(241장)는 중간 크기 클래스다. 이 두 차종은 닮은 차종(Ram 2500, Silverado)과 짝을 이룬다.
- 따라서 **이미지 수만으로는 어려운 클래스를 다 설명할 수 없다.** 외형 유사성이 또 다른 요인일 가능성이 있다. 다만 상관계수 하나와 사례 몇 개로 어느 쪽이 더 큰 원인인지는 결론 낼 수 없다.

### 5-4. 무작위 초기화에서는 "다른 제조사" 오류가 오답의 대부분이다
같은 검증 세트에서 본 실험의 A 모델(사전학습 + 증강, 3 seed 평균)과 비교한다. 분모를 섞지 않도록 두 기준을 함께 쓴다.

| | 기준 CNN (무작위 초기화, 동현) | 본 실험 A (사전학습 + 증강) |
|---|---:|---:|
| 전체 오류율 (검증 이미지 대비) | 23.0% | 5.8% |
| 다른 제조사 오류 (검증 이미지 대비) | **16.8%** (2,991장) | 3.2% (576장) |
| 같은 제조사 오류 (검증 이미지 대비) | 6.1% | 2.5% |
| 오답 중 다른 제조사 비중 | **73%** | 56% |

- 무작위 초기화 모델은 **오답의 73%가 다른 제조사로 틀린 경우**다.
- 본 실험 A에서도 다른 제조사 오류는 오답의 56%로 여전히 크다. 그런데 본 실험의 제조사 계층(B)은 이 오류를 일관되게 줄이지 못했다(`04_results_analysis.ipynb` §4-1).
- 기준 모델과 A는 사전학습뿐 아니라 증강·optimizer·학습률 스케줄·epoch이 **함께** 다르다. 그래서 16.8% → 3.2%의 감소를 사전학습만의 효과로 볼 수 없다.
- "무작위 초기화 조건에서는 제조사 계층이 더 도움이 될 것"이라는 생각은 **검증되지 않은 가설**이다. 확인하려면 다른 설정은 고정하고 무작위 초기화/사전학습 × Flat/계층형을 비교하는 2×2 실험이 필요하다.

## 6. 다음에 할 일 (Activity 3 후보)

같은 분할·전처리·학습량을 유지하고 한 번에 하나씩 바꾼다.

> 사전학습·증강을 쓴 본 실험(A·B·C × 3 seed)은 이미 끝났다. 결과와 해석은 `../04_results_analysis.ipynb`에 있다.

1. **과적합 대응:** 데이터 증강, weight decay, 학습률 스케줄. 가장 큰 문제(19%p 차이)를 직접 겨냥한다.
2. **요인 분리:** 본 실험 A는 사전학습·증강·optimizer·스케줄·epoch을 한꺼번에 바꿨다(정확도 77% → 94%). 하나씩 바꿔야 어느 요인이 효과를 냈는지 알 수 있다.
3. **계층형 분류:** 다른 제조사 오류가 오답의 73%이므로, 무작위 초기화 조건에서 제조사·차체 유형 계층의 효과를 확인한다(2×2 실험).
4. **형제차 대응:** 고해상도 입력(엠블럼·그릴), 혼동 기반 그룹. 그룹은 학습 세트 내부에서 만든다.
5. **오답 사진 검토:** 새 학습보다 먼저, 주요 혼동 쌍의 사진을 직접 보고 원인 후보를 좁힌다.
